¿Para quién es CsZip?

Diseñado para quienes necesitan comprimir y verificar archivos sin dependencias pesadas ni GUIs.

Desarrolladores

Comprime y verifica artefactos de build, backups de DB o logs directamente desde el pipeline.

DevOps / Sysadmins

Automatiza backups con verificación de integridad. Ideal para scripts en servidores headless vía SSH.

Científicos de datos

Comprime datasets enormes con memoria constante gracias al procesamiento streaming por bloques.

Entusiastas de Rust

Proyecto open source modular con LZ77+Huffman implementado desde cero. Ideal para aprender y contribuir.

Dónde sacarle más provecho

Desarrollo local

Comprime artefactos de build, logs de debugging o backups rápidos sin salir de la terminal.

SSH remoto

Servidores headless donde no hay GUI. CsZip funciona en cualquier terminal a través de SSH.

Homelab / Raspberry Pi

Binario pequeño (~3 MB), consumo mínimo de RAM. Perfecto para ARM64 y entornos con recursos limitados.

CI/CD pipelines

Comprime artefactos, verifica integridad de archivos y descomprime dependencias en pipelines automatizados.

Instalación

Rust 1.70+ y Cargo. En un minuto estás comprimiendo.

Script automático

$ curl -fsSL https://raw.githubusercontent.com/user/CsZip/main/install.sh | sh

Compilar desde fuente

$ git clone https://github.com/user/CsZip.git && cd CsZip && cargo build --release

Windows (PowerShell)

PS> powershell -ExecutionPolicy Bypass -Command "Invoke-Expression (Invoke-WebRequest -Uri 'https://raw.githubusercontent.com/user/CsZip/main/install.ps1' -UseBasicParsing).Content"

Requisitos mínimos

Rust 1.70+

Toolchain completa con rustup. Binario único y optimizado con LTO.

~3 MB en disco

Binario release optimizado con LTO, strip y panic=abort. Consumo mínimo de RAM incluso con archivos de GB.

unrar (optativo)

Solo si quieres extraer archivos .rar. CsZip delega en unrar del sistema.

¿Dónde se instala?

  • Binario: ~/.cargo/bin/cszip
  • Scripts: scripts/dev.sh, scripts/build.sh
  • Logs: vía RUST_LOG a stderr

Primeros Pasos

De cero a tu primer archivo comprimido en 30 segundos.

1

Comprime un archivo

Usa LZ77+Huffman para comprimir a formato .cz nativo.

$ cszip compress datos.bin
2

Verifica integridad

Revisa checksums CRC-32, CRC-64 y ADLER-32 del archivo .cz.

$ cszip verify datos.bin.cz
3

Inspecciona metadatos

Muestra bloques, niveles de compresión y checksums.

$ cszip info datos.bin.cz
4

Descomprime

Extrae formato .cz nativo, .zip estándar o .rar vía unrar.

$ cszip decompress datos.bin.cz
5

Lista bloques

Muestra la tabla de bloques y ratios de compresión detallados.

$ cszip list datos.bin.cz

Compresión LZ77+Huffman

Algoritmo nativo de compresión sin pérdida. 9 niveles de compresión (0-9) para balancear velocidad y ratio.

Soporte ZIP nativo

Lee y escribe archivos .zip usando la crate zip con compresión deflate. Intercambiable con formato .cz.

Extracción RAR

Descomprime .rar delegando en unrar del sistema. Integración segura con subprocesos.

Verificación triple

CRC-32, CRC-64 y ADLER-32 por bloque más CRC-64 global. Protección activa contra zip bombs.

Streaming por bloques

Procesa archivos de gigabytes con memoria constante. E/S bufferizada sin cargar todo en RAM.

Portabilidad universal

Linux, macOS y Windows. Instaladores para Ubuntu, Debian, Fedora, RHEL, Arch y más.

Modos disponibles

compress Comprimir

Comprime a formato .cz (nativo) o .zip. Niveles 0-9, algoritmo LZ77+Huffman o STORE.

decompress Descomprimir

Extrae .cz, .zip y .rar. Output personalizado con -o, sobrescritura con -f.

verify Verificar

Revisa checksums de cada bloque más footer global. Salta verificación con --no-verify.

info / list Inspeccionar

info muestra metadatos detallados. list tabla de bloques con ratios de compresión.

Comandos

Referencia completa de todo lo que puedes hacer desde la CLI.

compresión avanzada 
$ cszip compress -l 9 archivo.txt
$ cszip compress -a lz77-huffman datos.bin

Resumen de comandos

Opciones de compresión

Opción Descripción
-l, --level <N> Nivel de compresión 0-9 (default: 6)
-a, --algorithm <algo> Algoritmo: lz77-huffman | store
-o, --output <archivo> Nombre de archivo de salida personalizado
-f, --force Sobrescribir si el archivo destino existe
--no-verify Saltar verificación de checksums (más rápido)

Formato .cz

Estructura binaria del formato nativo de CsZip.

  File Header (16 bytes)
Magic 0x435A · versión · algoritmo · flags
  Block 0
Header 12B + datos + CRC-32/CRC-64/ADLER-32
  Block 1
  ...
  File Footer (12 bytes)
Marker 0xFE · nº bloques · tamaño · CRC-64 global

El formato .cz está diseñado para streaming seguro. Cada bloque se verifica individualmente y el footer contiene un checksum global que detecta truncamientos o corrupción. La especificación completa está en FORMAT.md.

Seguridad integrada

  • Triple checksum por bloque (CRC-32, CRC-64, ADLER-32)
  • CRC-64 global en el footer de archivo
  • Protección activa contra zip bombs (denegación de servicio)
  • Validación redundante en cada operación de descompresión

Configuración

Variables de entorno para personalizar el comportamiento.

Nivel de compresión

El nivel por defecto es 6. Puedes cambiarlo siempre con -l. Nivel 0 = STORE (sin compresión), nivel 9 = máxima compresión.

Rendimiento

El procesamiento por bloques mantiene el uso de memoria constante. Para archivos muy grandes, CsZip usa E/S bufferizada con buffers de tamaño configurable.

Verificación

Por defecto toda descompresión verifica checksums. Puedes saltar este paso con --no-verify para máximo rendimiento cuando la integridad no es crítica.

Variables de Entorno

Controla el comportamiento de CsZip desde el entorno.

Variable Descripción
RUST_LOG Nivel de log (error, warn, info, debug, trace). Los logs van a stderr.
CSZIP_BUFFER_SIZE Tamaño del buffer de E/S en bytes (default: 65536).
CSZIP_NO_COLOR 1 para deshabilitar colores en la salida.

FAQ

Respuestas rápidas a dudas frecuentes.

¿Qué diferencia a .cz de .zip?

.cz es un formato con verificación de integridad por bloque (triple checksum), streaming y protección anti zip bombs. ZIP es el estándar universal — CsZip soporta ambos.

¿CsZip puede abrir archivos .zip existentes?

Sí, CsZip lee y escribe archivos .zip nativamente usando la crate zip con compresión deflate. También extrae .rar delegando en unrar del sistema.

¿Qué tan seguro es el formato .cz?

Cada bloque lleva CRC-32, CRC-64 y ADLER-32. El archivo completo tiene un CRC-64 global en el footer. CsZip también detecta y rechaza zip bombs activamente.

¿Puedo comprimir archivos de varios GB?

Sí. El procesamiento streaming por bloques mantiene la memoria constante. Archivos de varios gigabytes se procesan sin problema en hardware limitado.

¿Necesito pagar algo?

No. CsZip es software libre bajo licencia MIT. Puedes usarlo, modificarlo y redistribuirlo sin restricciones.

¿En qué plataformas corre?

Linux (amd64/arm64), macOS (amd64/arm64) y Windows (amd64/arm64). Instaladores para Ubuntu, Debian, Fedora, RHEL y Arch.
